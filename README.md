# Palette-Swap

Minecraftテクスチャ編集用のWindowsデスクトップアプリです。Electronで起動し、PNGやZIPを保存ダイアログから出力できます。

アプリの左側に素材ライブラリがあり、同梱のMinecraftテクスチャ全体（ブロック、アイテム、エンティティ、GUIなど）を検索して編集できます。選んだ画像は16×16に合わせて読み込み、透明部分を保ちながら最大11色に整理します。素材一覧は表示を軽くするため一度に最大250件まで表示し、検索やカテゴリで絞り込めます。

ヘルメット・チェストプレート・レギンス・ブーツなどの防具は、素材ライブラリに素材ごとの画像を個別に表示します。選んだ防具の実際の画像を編集し、PNGまたはZIPで保存できます。革・チェーン・鉄・金・ダイヤ・ネザライトに加えて、素材がある銅防具やカメのヘルメットも表示します。画像を自動色抽出で取り込んでも、取込専用の素材が一覧に増え続けることはありません。元画像の色に合わせる場合は、読み込み時の「選択中の素材の色に合わせる」を選んでください。

画面は上部メニュー、左のツール・素材ライブラリ、中央のピクセル編集面、右のカラー・レイヤーパネルに分かれています。素材一覧は防具・剣・つるはし・斧・シャベル・クワなど種類ごとに分類されます。通常アイテムの素材違いは一覧上で重複表示せず、各セットの編集画面で切り替えます。防具は素材ごとの画像を個別に選択できます。テクスチャを選ぶと編集タブが開き、複数の画像を切り替えて編集できます。新規タブボタンで空のテクスチャを開き、各タブの×ボタンで閉じられます。タブごとに画像、色、選択範囲、ツール、Undo/Redo履歴を保持します。

羊毛、カーペット、コンクリート、テラコッタ、色付きガラス、ベッド、ろうそくなど、既知の色違いブロックは色別のバリエーションとしてまとめて編集できます。「ピクセル編集を同期」をオフにすると、各素材・色のテクスチャを個別に編集でき、編集内容とUndo/Redo履歴も種類ごとに保持されます。同期を再びオンにすると、選択中の種類の編集内容がほかの種類にも反映されます。パンなど素材違いのない画像は「単一画像のカラー」として1種類だけを編集・保存します。剣やツール、防具などは素材違いの画像が存在する場合だけ、その素材を一覧に表示します。選択範囲のコピー・切り取り・反転などの操作は左端のツール列にあります。ZIP出力は元のテクスチャのカテゴリ（block/itemなど）に合わせたパスで保存します。

## 開発起動

Node.jsをインストールした後、プロジェクトのフォルダーで実行します。

```powershell
npm install
npm start
```

## Windowsインストーラー作成（ローカル確認用）

```powershell
npm install
npm run dist:win
```

作成されたインストーラーは `dist` フォルダーに出力されます。このコマンドはローカルでインストーラーを作るだけで、GitHub Releasesには公開しません。

## Windows版のリリースと再デプロイ

配布先は [GitHub Releases](https://github.com/sirotumekuma/PaletteSwap/releases) です。ソースの変更を反映して再配布する場合は、次の手順でWindowsインストーラーをビルドし、新しいGitHub Releaseに公開します。

1. 変更を確認し、リリースするソースをコミットしてGitHubにプッシュします。
2. `package.json` のバージョンを、直近のリリースより大きい未使用の番号に上げます。`package-lock.json` も同じ番号に更新してください。たとえば現在のバージョンが `1.0.4` なら、次は `1.0.5` です。PowerShellから次のコマンドを実行すると、両方のファイルのパッチバージョンを上げられます。

   ```powershell
   npm version patch --no-git-tag-version
   ```

3. バージョン変更をコミットしてGitHubにプッシュします。
4. GitHub Releaseを作成できる権限を持つトークンを用意します。Fine-grained tokenの場合は、このリポジトリに対するContentsの読み書きを許可してください。トークンをソースコードや設定ファイルに書き込まず、PowerShellの環境変数に設定して公開コマンドを実行します。

```powershell
$env:GH_TOKEN = "GitHubのアクセストークン"
npm run release:win
Remove-Item Env:\GH_TOKEN
```

`release:win` はWindows用インストーラーをビルドしてGitHub Releaseに公開します。完了後、[GitHub Releases](https://github.com/sirotumekuma/PaletteSwap/releases)で新しいバージョンが公開され、`PaletteSwap-Setup-<バージョン>.exe` と `latest.yml` などの更新ファイルが添付されていることを確認してください。エラーでコマンドが終了した場合は、原因を解消してから環境変数を削除してください。

リリース後、既にインストールされているアプリは起動時に更新を確認し、新版をバックグラウンドでダウンロードします。準備完了後、画面上部の「再起動して更新」を押すと適用されます。自動更新を利用するには、利用者がPaletteSwapのインストーラー版を一度インストールしている必要があります。インストーラーを手動で配布する場合も、GitHub Releaseに公開された同じバージョンの `.exe` を利用してください。
