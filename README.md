# Palette-Swap

Minecraftテクスチャ編集用のWindowsデスクトップアプリです。Electronで起動し、PNGやZIPを保存ダイアログから出力できます。

アプリの左側に素材ライブラリがあり、同梱のMinecraftテクスチャ全体（ブロック、アイテム、エンティティ、GUIなど）を検索して編集できます。選んだ画像は16×16に合わせて読み込み、透明部分を保ちながら最大11色に整理します。素材一覧は表示を軽くするため一度に最大250件まで表示し、検索やカテゴリで絞り込めます。

ヘルメット・チェストプレート・レギンス・ブーツの画像を選ぶと、防具の種類が革・チェーン・鉄・金・ダイヤ・ネザライトの6種類に切り替わります。色を調整し、選択中の種類をPNG保存するか、6種類をZIPにまとめて保存できます。通常のアイテムの素材バリエーションは従来の一覧を維持します。画像を自動色抽出で取り込んでも、取込専用の素材が一覧に増え続けることはありません。元画像の色に合わせる場合は、読み込み時の「選択中の素材の色に合わせる」を選んでください。

画面は上部メニュー、左のツール・素材ライブラリ、中央のピクセル編集面、右のカラー・レイヤーパネルに分かれています。素材一覧は防具・剣・つるはし・斧・シャベル・クワなど種類ごとに分類され、素材違いは一覧上で重複表示せず、各セットの編集画面で切り替えます。テクスチャを選ぶと編集タブが開き、複数の画像を切り替えて編集できます。新規タブボタンで空のテクスチャを開き、各タブの×ボタンで閉じられます。タブごとに画像、色、選択範囲、ツール、Undo/Redo履歴を保持します。

羊毛、カーペット、コンクリート、テラコッタ、色付きガラス、ベッド、ろうそくなど、既知の色違いブロックは色別のバリエーションとしてまとめて編集できます。「ピクセル編集を同期」をオフにすると、各素材・色のテクスチャを個別に編集でき、編集内容とUndo/Redo履歴も種類ごとに保持されます。同期を再びオンにすると、選択中の種類の編集内容がほかの種類にも反映されます。パンなど素材違いのない画像は「単一画像のカラー」として1種類だけを編集・保存します。剣やツール、防具などは素材違いの画像が存在する場合だけ、その素材を一覧に表示します。選択範囲のコピー・切り取り・反転などの操作は左端のツール列にあります。ZIP出力は元のテクスチャのカテゴリ（block/itemなど）に合わせたパスで保存します。

## 開発起動

Node.jsをインストールした後、プロジェクトのフォルダーで実行します。

```powershell
npm install
npm start
```

## Windowsインストーラー作成

```powershell
npm run dist:win
```

作成されたインストーラーは `dist` フォルダーに出力されます。

## 自動更新のリリース

配布先は [GitHub Releases](https://github.com/sirotumekuma/Palette-Swap/releases) です。新しい更新を配布するときは、`package.json` の `version` を前回より大きい値に変更し、PowerShellでGitHubのリリース作成権限を持つアクセストークンを環境変数に設定してからビルド・公開します。

```powershell
$env:GH_TOKEN = "GitHubのアクセストークン"
npm run release:win
Remove-Item Env:\GH_TOKEN
```

コマンドが作成したGitHub Releaseを公開すると、Windowsインストール版は起動時に更新を確認し、新版をバックグラウンドでダウンロードします。準備完了後、画面上部の「再起動して更新」を押すと適用されます。トークンはソースコードや設定ファイルに保存しないでください。自動更新を使うには、更新機能付きのインストーラーを利用者へ一度配布してインストールしてもらう必要があります。
